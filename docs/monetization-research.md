# Monetization Research — Uzi Network

**Compiled:** August 2026
**Source:** Web research, ad-network forums (r/adsense, r/Publishers, WebmasterWorld), direct outreach to publishers, public rate cards.

## TL;DR

**Short-term (0 - 50K visits/month):** Affiliate links only. Optionally layer Monetag/Adsterra at 10K+.

**Mid-term (50K - 100K):** Apply to Ezoic or Mediavine. Sunset the smaller networks.

**Long-term (100K+):** Mediavine or Raptive. Stack with direct ad deals once you're at 200K+.

## Why this section exists

This is the playbook. We (and you) should re-evaluate quarterly because:

- RPMs change monthly
- Networks get acquired, pivot, or die
- New networks emerge (Ezoic was unknown in 2017; Raptive didn't exist until 2024)
- Algorithm shifts affect traffic value

## The 6-tier network stack

### Tier 0: Affiliate only (0 - 1K visits/month)

**Don't run ads.** You'll make less than $5/month and damage user trust.

Instead:
- Amazon Associates (1% - 10% commission)
- Impact, PartnerStack for SaaS (recurring 20-50%)
- Direct brand programs when available

Realistic revenue at 1K visits/month with 2% CTR: $10-50/month.

### Tier 1: Monetag (1K - 10K visits/month)

- Easiest approval
- Pay per 1K impressions: $1.50-3.00 (US traffic)
- Web push notifications can be a steady side-channel

### Tier 2: Monetag + Adsterra (10K - 30K)

- Add Adsterra for smart CPM bidding
- Adsterra RPM: $2.00-4.50 (US traffic)
- Popunders become 70%+ of revenue — accept the trade-off

### Tier 3: Adsterra + Ezoic (30K - 50K)

- Ezoic's AI optimizes placement for you
- Ezoic RPM at this tier: $5-10 (US)
- Run them in parallel; Ezoic fills back

### Tier 4: Mediavine (50K+)

- Industry-standard premium network
- 50K sessions/month minimum (last 30 days)
- RPM: $25-40 (US traffic)
- 75% revenue share to publisher

### Tier 5: Raptive (100K+)

- Highest RPMs
- 100K pageviews/month minimum
- RPM: $30-50 (US traffic)
- Better than Mediavine for some niches (food, parenting, lifestyle)

## What we are NOT going to do

- **Auto-refresh ads** — Google penalizes these
- **Aggressive interstitials** — same reason
- **Cookie stuffing** — illegal in most jurisdictions
- **Third-party tracking scripts** (Google Analytics, Facebook Pixel) — privacy concerns
- **Pay-per-click arbitrage** — high churn, low margins
- **Multi-level "monetization platforms"** that promise easy money — they're usually scams

## What we ARE going to do

1. Build the email list from day one (we own the audience, the network doesn't)
2. Affiliate links as primary revenue for the first 6 months
3. Layer in ads once we hit 10K visits/month
4. Apply to Mediavine as soon as we hit 50K (don't wait)
5. Re-evaluate the stack every quarter

## Quarterly review checklist

- [ ] Check current RPMs across all networks
- [ ] Compare against premium tier (Mediavine/Raptive) — am I close to qualifying?
- [ ] Read r/Publishers and r/adsense for the latest on each network
- [ ] Check if any new networks launched and are worth applying to
- [ ] Review affiliate program terms — any new programs in my niche?
- [ ] Audit ad placements for UX impact
