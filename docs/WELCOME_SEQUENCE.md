## Automation Notes

**Buttondown setup:**

1. Sign up at https://buttondown.email/ (free up to 100 subscribers)
2. Create automation: "When subscriber added → send Email 1 → wait 2 days → send Email 2..."
3. Each email is its own draft in Buttondown
4. Use the `{{ subscriber.email }}` and `{{ subscriber.first_name }}` merge tags
5. Buttondown handles unsubscribe, bounce, and spam complaint processing automatically

- Open rate: 40–60% (industry standard for welcome series)

## A/B Tests to Run

After 30 days and 100+ subscribers, A/B test:

1. **Email 1 subject line:**
   - A: "You're in. Here's where to start."
   - B: "Welcome to Uzi Network — start with these 3 reviews"

2. **Send times:**
   - A: 8am recipient local time
   - B: 6pm recipient local time

3. **Email length:**
   - A: Short (3 links max)
   - B: Long (5–7 links)

Pick the winner. Standard A/B test, 1,000+ sends per variant for significance.
